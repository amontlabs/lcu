# LCU 0.16.0

**Any MCP client can now use LCU: register `lcu mcp`, and app approvals work even when the client cannot show them.**

## Changes

- **New: `lcu mcp` for MCP clients without an LCU adapter**, such as Amp. Register `<installed path>/bin/lcu mcp` as a stdio MCP server in the client (add `--chrome` or `--audio` after `mcp` if wanted). Before, a client registered with bare `lcu` that cannot show MCP approval forms failed the first use of every app with `nodeRepl.createElicitation is unavailable`. Now a client that supports form elicitation shows the approval with the original choices (allow once, for the session, always, or decline). Otherwise the model is told to run `lcu apps allow <App>` on macOS; approving it with Touch ID or your password allows that app for every agent until `lcu apps revoke <App>`. Each connection is one LCU turn, interrupted when the client disconnects. Bare `lcu` and every `lcu setup --agent` registration are unchanged. No real client has been driven against a desktop with `lcu mcp` yet; see [Other MCP clients](https://github.com/amontlabs/lcu/blob/main/docs/INSTALLATION.md#other-mcp-clients) for setup and limits. ([#92](https://github.com/amontlabs/lcu/issues/92), [#95](https://github.com/amontlabs/lcu/pull/95), thanks @ipruning for the report)
- **`lcu setup --export`: `mcp.json` now runs `lcu mcp`.** A host that called `turn_ended` through the exported `mcp.json` must use the [shared client](https://github.com/amontlabs/lcu/blob/main/docs/ADAPTERS.md#shared-client-contract) instead. `codex.mcp.json` is unchanged. ([#95](https://github.com/amontlabs/lcu/pull/95))
- **Windows candidate: installation works with the current Store app.** The installer now handles webpack-bundled Store builds (observed on `OpenAI.Codex` 26.1117.4957.0) and retries the staged copy's rename when Windows Defender or indexing briefly holds a file. Windows remains a deferred candidate with no new live verification. ([#91](https://github.com/amontlabs/lcu/pull/91), thanks @Ivocin, who wrote the fix)

## Upgrading

Run `lcu update`, then restart the agents that use LCU. To use another MCP client, register `lcu mcp` in it after updating. If you imported an earlier `--export` into a host that drives LCU's lifecycle itself, keep that host on the shared client. To go back, reinstall 0.15.0.
