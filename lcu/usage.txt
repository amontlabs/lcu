Usage: lcu mcp [--chrome] [--audio]
       lcu [--chrome] [--audio] [--mcp-discovery-compat]
       lcu setup OPTIONS
       lcu browser install
       lcu browser status [--browser FAMILY]
       lcu apps [list|allow APP|revoke APP] [--json]   (macOS)
       lcu cross-turn [status|on|off] [--json] [--unattended]
       lcu origins [list [--session ID] [--json]]
       lcu origins forget ORIGIN [--session ID | --all-sessions] [--allowed | --denied]
       lcu prune [--keep N] [--yes]
       lcu update [--check [--json]] [--yes]
       lcu doctor
       lcu status [--json]
       lcu --version

Register `lcu mcp` with any MCP client that `lcu setup --agent` does not cover. It shows app approvals as MCP form elicitation; without it, on macOS, it tells the agent to run `lcu apps allow APP`.
Bare `lcu` (no arguments) starts the original computer-use stdio MCP server that `lcu setup` registers through LCU's adapters; do not register it with other clients. `lcu --chrome` also enables its browser surface; `lcu setup --chrome` registers that command. `lcu --audio` enables the original optional computer-audio API; `lcu setup --audio` registers that command.
